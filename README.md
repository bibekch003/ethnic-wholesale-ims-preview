# Ethnic Wholesale IMS — interface preview

A **static snapshot** of the Ethnic Wholesale IMS interface, published so the
design can be reviewed without installing anything or connecting a database.

- 16 screens: dashboard, products, inventory, purchases, suppliers, customers,
  sales orders, invoices, payments, returns, reports, automation, WhatsApp,
  users, settings, development
- Sample data only. No database, no login, no server.
- Buttons and filters are inert — this is a picture of the app, not the app.

The real application (Next.js, TypeScript, Supabase, event-driven automation)
lives in a **private** repository. This repository contains only the rendered
HTML output, produced from a production build running in demo mode.

Open `index.html` or the Pages URL to start at the dashboard.
